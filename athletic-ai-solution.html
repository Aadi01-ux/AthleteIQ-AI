Problem Statement

Modern sports coaching faces a critical data gap — athletes generate vast amounts of performance data across training sessions, matches, and recovery periods, yet most coaching staff lack the tools to analyse it quickly and act on it intelligently. Manual analysis is time-consuming, error-prone, and rarely personalised. There is a pressing need for an intelligent, automated system that transforms raw athlete metrics into actionable insights in real time.

Specific challenges include:

  • Data Overload: Coaches manage metrics across heart rate, VO₂ max, strength, agility, endurance, recovery, and match statistics simultaneously.
  • Lack of Personalisation: Generic training templates do not account for individual athlete profiles, injury history, or current fitness levels.
  • Delayed Feedback: Performance reports are often produced days after sessions, missing the window for timely intervention.
  • No Predictive Support: Coaches rely on intuition rather than data-driven predictions for load management and injury prevention.

Proposed Solution

The proposed solution is a multi-agent AI-powered Athlete Performance Analysis Assistant built using Groq API, Flask, and large language models to provide personalised, real-time athletic performance guidance. The system addresses challenges in performance monitoring, training optimisation, and preventive sports medicine through an intelligent, modular four-agent architecture.

At its core, the solution uses a Retrieval-Augmented Generation (RAG) pipeline that fetches structured athlete metrics — training session records, fitness scores, match statistics, and recovery data — from a SQLite database seeded from CSV files. Data is aggregated and contextualised using Pandas, then passed as rich structured context to LLM agents powered by Groq's inference API, enabling sub-second AI responses at scale.

The Four AI Agents

The system consists of four specialised agents, each owning a distinct responsibility in the analysis pipeline:

🗃️
Agent 1

Athlete Data Agent

Acts as the retrieval layer — reads and aggregates athlete session records, fitness metrics, and match statistics from SQLite using Pandas. Constructs structured context blocks that feed all downstream agents.

  • RAG over CSV / SQLite data
  • Pandas-based metric aggregation
  • Time-series data preparation for Chart.js
  • Comparison data across all athletes
📊
Agent 2

Performance Analysis Agent

Analyses performance trends over time to identify strengths, weaknesses, and risk flags. Uses retrieved athlete context to ground all LLM-generated insights in real data.

  • Trend analysis (improving / declining metrics)
  • Top 3 strengths and improvement areas
  • Risk flags: low recovery, injury incidents
  • Evidence-based, data-cited recommendations
🏋️
Agent 3

Training Recommendation Agent

Generates fully personalised weekly training plans by combining identified weaknesses with sport-specific conditioning principles and the athlete's current load and recovery state.

  • 7-day day-by-day training schedules
  • Exercise selection targeting weak metrics
  • Intensity levels and session types
  • Nutrition and recovery tips
📋
Agent 4

Coaching Insights Agent

Produces formal coaching reports suitable for sports organisations. Synthesises outputs from all upstream agents into a structured professional document covering performance highlights, concerns, tactical observations, and development plans.

  • 7-section formal coaching report
  • Short-term (4-week) and long-term goals
  • Downloadable plain-text report (.txt)
  • Coach notes integration

Multi-Agent Workflow Orchestration

A centralised AthleteIQ Workflow Orchestrator chains all four agents sequentially, ensuring each stage has full access to the outputs of previous stages. The pipeline runs on a single API call from the frontend and returns a unified JSON response.
